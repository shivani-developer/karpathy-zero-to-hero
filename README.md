# Karpathy Zero to Hero — my exercises

Notebooks I worked through while following Andrej Karpathy's [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) course. Learning material, not a library.

## Contents

- `makemore2.ipynb` — MLP character-level language model on names
- `makemore-backpropninja.ipynb` — manual backprop exercise (no autograd)
- `nanogpt.ipynb` — GPT from scratch, trained on tiny Shakespeare
- `input.txt` — tiny Shakespeare corpus
- `names.txt` — standard makemore dataset

A few scratch and duplicate notebooks (`Untitled.ipynb`, `makemore2-Copy*.ipynb`) are kept as-is.
